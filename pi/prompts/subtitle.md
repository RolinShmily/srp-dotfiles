# 音视频字幕处理工作流

- **音视频目标**: `${1:-"(未指定，请通过交互或上下文确认)"}`
- **参考台词本**: `${2:-"(无/可选)"}`

---

### 执行步骤

#### 1. 参数与前置检查
- 检查 `$1` 路径是否有效。若未提供参数或路径不存在，使用 `ask_user_question` 询问用户音视频文件路径。
- 确认系统是否已安装 `videocaptioner`。若未安装，提示安装方式并等待指示。
- 若未提供 `$2`，可简要询问用户是否有原版演讲稿/台词本（有台词本可大幅提升专有名词和断句精度）。

#### 2. 语音转录（ASR）
执行语音转录生成基础 `.srt` 文件：
```bash
videocaptioner transcribe "$1" --asr bijian -o "${1%.*}.srt"
```
*(注：`bijian` 免费支持中英文；若识别其他小语种可改用 `--asr whisper-api`)*

#### 3. 字幕智能精修与对齐

转录完成后，使用 `read` 读取生成的 `.srt` 文件：

- **分支 A：提供了参考台词本（高精度对拍）**
  1. 读取台词本内容。
  2. 逐句比对：纠正 ASR 同音错字、专有名词、标点，按台词本修正断句。
  3. 使用 `edit` 精准修改字幕文本。**【核心铁律】绝对保持原字幕序号与时间轴（`HH:MM:SS,mmm --> HH:MM:SS,mmm`）格式不变**。
  4. 遇到长文本分批处理，时间轴略有偏差的根据语速就近微调。

- **分支 B：无参考台词本（语境纠错）**
  1. 结合上下文语境修正明显的错别字、漏字和语法歧义。
  2. 保持原意与口语表达，不确定处保留原样并在交付时说明。

#### 4. 交付与扩展
- 告知用户最终生成的 `.srt` 绝对路径。
- 提供简短质量报告（总句数、修正要点、存疑标记）。
- 询问是否需要后续处理（如双语翻译、压制烧录进视频等）。
