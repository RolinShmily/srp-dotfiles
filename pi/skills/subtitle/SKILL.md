# 音视频字幕处理工作流 (Subtitle Workflow)

本技能提供从音视频语音识别（ASR 转录）到大模型智能校对、台词本精准对齐与字幕交付的全流程支持。

---

## 核心流程

```
[音视频输入] ──► 1. 前置参数与工具检查
                     │
                     ▼
                 2. 语音识别转录 (ASR) ──► 生成原始 .srt
                     │
                     ▼
                 3. 字幕智能精修与对齐
                    ├── 分支 A: 提供参考台词本 (高精度对齐纠错)
                    └── 分支 B: 无台词本 (语境纠错与口语精简)
                     │
                     ▼
                 4. 结果交付与后续处理 (翻译 / 压制)
```

---

## 详细步骤

### 1. 前置参数与环境检查

1. **识别输入参数**：
   - **音视频目标路径**：若用户未指定，使用 `ask_user_question` 询问音视频文件绝对/相对路径。
   - **参考台词本/演讲稿（可选）**：询问用户是否有原版文本。提供参考台词本可大幅消除同音字错误和断句偏差。
   - **目标识别语言与 ASR 引擎**：
     - 中英文优先推荐：`bijian`（免费免 Key，速度快，适合绝大多数中文/英文音视频）；
     - 多语种/小语种推荐：`whisper-api` 或 `whisper-local`。

2. **工具链检查**：
   - 检查系统是否安装 `videocaptioner` 或 `ffmpeg`：
     ```bash
     which videocaptioner || which ffmpeg
     ```
   - 若未安装 `videocaptioner`，可提示通过 pip/uv 安装或使用 ffmpeg 配合在线 API：
     ```bash
     pip install videocaptioner
     ```

---

### 2. 语音识别转录 (ASR)

执行语音转录命令，生成初始 `.srt` 字幕文件：

```bash
# 默认中文/英文转录
videocaptioner transcribe "<media_path>" --asr bijian -o "<output_srt_path>"

# 或指定其他 ASR 引擎
videocaptioner transcribe "<media_path>" --asr whisper-api -o "<output_srt_path>"
```

---

### 3. 字幕智能精修与对齐

转录完成后，使用 `read` 工具读取生成的 `.srt` 文件，根据是否有参考文本展开精修：

#### 分支 A：提供了参考台词本（高精度对拍）
1. 读取参考台词本内容。
2. 逐句进行语义与时间轴比对：
   - **纠正错字**：依据台词本修复 ASR 的同音错别字、专有名词、人名、术语；
   - **标点与断句**：去除无意义的口头语气词，按照台词本自然停顿规范标点符号；
   - **格式铁律**：**严禁改动原字幕序号与时间轴格式**（必须严格遵循 `00:00:01,234 --> 00:00:03,567` 结构）。
3. 使用 `edit` 工具对 `.srt` 文件执行精准局部替换。

#### 分支 B：无参考台词本（语境自动纠错）
1. 结合上下文语境推断并修正明显的语音转录错误、断句不通顺与错别字。
2. 保持原说话者的语义与语气，对于发音模糊且无法推断的词句保留原样并在最终交付时作标记说明。
3. 使用 `edit` 工具精准更新 `.srt` 内容。

---

### 4. 交付与扩展服务

1. **报告摘要**：
   - 告知用户最终精修 `.srt` 文件的绝对路径；
   - 输出简明报告：总字幕句数、核心修正点、存疑词句标记。
2. **后续扩展（按需询问）**：
   - **双语翻译**：若用户需要双语字幕，逐句生成高质量译文并按标准双语格式写入；
   - **视频压制**：若需硬字幕压制，调用 `ffmpeg` 执行烧录：
     ```bash
     ffmpeg -i "<media_path>" -vf "subtitles='<output_srt_path>'" "<output_video_path>"
     ```
